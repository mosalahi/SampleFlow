# لقطات دليل الاستخدام

ضع لقطات الشاشة هنا بهذه الأسماء بالضبط ليعرضها `docs/USER_GUIDE.md`:

| اسم الملف | اللقطة المطلوبة |
|---|---|
| `overview.png` | الشكل العام وشريط التنقّل بعد الدخول |
| `login.png` | شاشة تسجيل الدخول |
| `entry.png` | شاشة إدخال بيانات اليوم |
| `dashboard.png` | لوحة المشرف (المؤشّرات + الجدول + الرسوم) |
| `export.png` | مثال ملف Excel أو PDF مُصدّر |
| `admin-centers.png` | إدارة المراكز |
| `admin-sampletypes.png` | إدارة أنواع التحاليل |
| `admin-users.png` | إدارة المستخدمين |
| `admin-permissions.png` | ضبط الصلاحيات الفردية |
| `admin-audit.png` | سجل التتبّع |

> صيغة PNG مفضّلة، بعرض ~1200px، وبدون بيانات حقيقية حسّاسة.
